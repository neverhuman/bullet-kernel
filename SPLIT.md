## Split Rules

- Jeryu is the initial source forge; GitHub is a configurable effect adapter,
  not source authority.
- No committed cross-repo `path = "../..."` dependencies; the hub's canonical
  JSON and policy rules are vendored and pinned by golden-vector tests.
- `crates/domain` has no I/O. Durable writes live in `crates/adapters` and
  `db/`.
- `contracts/openapi.yaml` is the API source of truth; `contracts/generated/`
  is regenerated by `bullet contracts generate` and checked by the fast lane.
- No Git worktrees; work only in the claimed canonical checkout.
- Documentation claims cite code and carry an evidence class
  (`COMPONENT_PROOF`, `SYNTHETIC_PROOF`, `TRANSACTION_PROOF`, `LIVE_PROOF`,
  `RELEASE_PROOF` per `bullet-farm/docs/release.md`); a receipt is never
  authority.
- Jeryu tags observed today are not annotated signed tags. `bullet-family
  forge pin` refuses `UNSIGNED_FORGE_TAG` until they are (J-5 / OD-D). Do not
  write "signed Jeryu tags" as a current fact.
